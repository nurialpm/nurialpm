## About Me

I am a Mathematics Undergraduate who develops software primarily with Python and Django. My work is centered on backend development, ERP systems, inventory workflows, and practical business applications, with an emphasis on clear domain models, reliable data handling, validation, testing, and maintainable architecture. I continuously improve my software engineering skills by building real-world projects and documenting the decisions behind them. My current public portfolio includes a Django-based habit tracking and analytics application with persistent data, automated checks, and a modular project structure. Alongside application development, I have a strong interest in Artificial Intelligence, Data Analysis, Topological Data Analysis, and Mathematical Research, particularly where computational tools can support structured reasoning and experimentation.
